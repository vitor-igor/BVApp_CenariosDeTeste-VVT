# Cenários de Teste Funcional

Esta pasta contém exclusivamente a documentação em Markdown dos dez cenários de teste funcional do BVApp, módulo Gestão de Pessoas e Controle de Acesso.

Os cenários estão agrupados por funcionalidade. Cada arquivo documenta um cenário independente, com seus requisitos relacionados, fluxo principal e alternativos, regras, dados, resultados esperados e autoria.

Esta documentação poderá ser aproveitada em etapas futuras de implementação e automação. Nesta etapa, ela não contém aplicação Flask, código executável nem scripts de testes.

## Cenários por funcionalidade

- [Autenticação](autenticacao/): CT001, CT002, CT004 e CT005.
- [Controle de acesso](controle_acesso/): CT003, CT006 e CT007.
- [Interface](interface/): CT008.
- [Painéis](paineis/): CT009 e CT010.

Consulte o [README principal](../README.md) para o catálogo completo e os requisitos relacionados.
